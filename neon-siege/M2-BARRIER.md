# M2 Barrier Foundation

## Goal

Introduce the first tower whose primary value is battlefield control rather than damage.

## Behavior

- Select Barrier with `3` on desktop or `BARRIER` on mobile.
- Barrier costs 90 credits.
- Barrier has 260 durability.
- Ground enemies stop at the Barrier and damage it over time.
- Heavy enemies destroy Barriers faster than normal enemies.
- Barrier visually exposes durability and a breach warning when destroyed.
- Existing Turret / Tesla targeting continues to work against enemies clustered at the Barrier.

## Playtest acceptance

1. Building a Barrier before a Tesla should create a visibly denser enemy cluster than using Tesla alone.
2. Shotgun should become more useful around a Barrier because enemies are intentionally held in a predictable zone.
3. A Barrier should buy meaningful time but eventually fail if unsupported.
4. Heavy enemies should make Barrier-only strategies clearly unsustainable.
5. Choosing Barrier should feel like a tactical tradeoff against spending the same credits on direct DPS.
