# Paper Trails / 書頁迷城

Mobile-first antique-book spatial puzzle built with PixiJS, TypeScript, and Vite.

## Current milestone

**P0 — Repository-complete scaffold**

This slice intentionally contains no final page-graph gameplay yet. It establishes a portrait PixiJS shell, explicit renderer bootstrap/fallback behavior, deterministic test/build scripts, and GitHub Pages-safe repository integration before P1 world-model work begins.

## Scripts

```bash
npm ci
npm test
npm run build
npm run dev
```

Production base path: `/2D-game-playground/paper-trails/`.

Product/MVP planning lives in `../docs/plans/paper-trails/`.
