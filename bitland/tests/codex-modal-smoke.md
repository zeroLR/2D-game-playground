# Codex modal smoke test

1. Launch Bitland in a mobile landscape viewport.
2. Open CODEX after recording at least 6 discoveries.
3. Verify gameplay HUD, joystick, and action controls are hidden while the Codex is open.
4. Verify at most 5 discoveries are rendered on one page and no entry crosses the modal footer.
5. Use PREV/NEXT to move between pages; verify PAGE X / Y updates and boundary buttons dim.
6. Close with CLOSE, C, or Escape and verify gameplay controls return without a queued jump/attack/dodge/interact action firing.
