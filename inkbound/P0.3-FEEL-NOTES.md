# P0.3 Feel Fix

## Device feedback

- Slow traversal can still fall into the gap before a raised platform.
- Slash input feels acceptable.
- Confirmed hits lack enough impact.

## Changes

### Context traversal

The previous implementation only injected vertical velocity for one frame. Once airborne, the player was no longer grounded, so the context ledge detector stopped running and slow stick input did not provide enough horizontal travel to reliably clear the 25px gap before the 42px rise.

The fix introduces a short 220ms context-jump carry state with a minimum 190px/s horizontal speed and extends the forward ledge probe to 48px. Normal free movement parameters are unchanged.

### Combat feedback

Keep the existing attack timing, but reinforce confirmed hits with three simultaneous channels:

1. Existing 55ms hit-stop.
2. Short 120ms, max 5px gameplay-camera shake.
3. High-contrast expanding ink impact burst at the contact point.

The slash arc is also thicker/darker. This keeps input timing stable while making hit confirmation visually explicit.
