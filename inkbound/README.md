# Inkbound

Mobile-portrait ink-wash 2D adventure prototype built with PixiJS v8.

## P0.1 Mobile Shell

- Logical resolution: `390x844`
- Gameplay viewport: `390x560`
- Control deck: `390x284`
- Touch virtual stick
- Three action inputs: `斬` / `身` / `墨`
- Placeholder ink-wash scene and player
- Responsive portrait scaling

## Run

```bash
npm install
npm test
npm run dev
```

P0.1 validates the portrait screen split and mobile touch ergonomics before movement/camera work in P0.2.
