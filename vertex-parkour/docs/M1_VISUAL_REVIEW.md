# M1 Visual Review — Polish Pass

This pass is based on the 2026-08-12 mobile runtime screenshot after the first M1 visual foundation merge.

## Current assessment

M1 is approximately 70% complete. The visual identity is now recognizable, but gameplay hierarchy and visual fatigue still need work before M1 can pass.

## Required polish

1. **Hazards**
   - Reduce visual size by roughly 20–30%.
   - Lower default magenta saturation/contrast.
   - Increase emphasis only when a hazard enters the player's immediate danger range.

2. **Player silhouette**
   - Make the hood/head proportion larger and the body smaller.
   - Preserve the cream hood + dark cloak identity.
   - Keep scarf/trail motion cues so the player remains the primary focal point.

3. **HUD**
   - Reduce the VERTEX logo footprint.
   - Keep Flow visually dominant.
   - Move HP away from the Flow value so the hierarchy is easier to scan.

4. **Crystals**
   - Remove the complete circular UI-like ring.
   - Use a soft aura / sparse particle treatment instead.

5. **Scene density**
   - Introduce deliberate breathing-space bands.
   - Avoid spawning hazard + crystal in every band.
   - Preserve alternating dense / rest beats to reduce sustained visual fatigue.

## M1 pass criteria

M1 passes only when a phone-scale runtime screenshot satisfies all of the following:

- the player is the first focal point;
- the next safe route is readable without studying the screen;
- hazards communicate threat without dominating the composition;
- crystals read as world objects rather than UI markers;
- the screen contains visible rest zones between dense gameplay clusters;
- the scene remains comfortable to watch for at least 30 seconds.
