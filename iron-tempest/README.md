# IRON TEMPEST

16-bit-inspired vertical shoot-'em-up roguelite prototype built with PixiJS.

## Prototype loop

- Automatic forward fire and arcade movement
- Hold Shift for Focus movement / smaller hitbox
- Enemy formations and aimed bullet pressure
- Elite enemies
- Scrap-based level ups
- Three module choices: Twin Barrel, Overclock, High Caliber

## Controls

- Move: WASD / Arrow keys
- Focus: Shift
- Upgrade: 1 / 2 / 3

## Development

```bash
npm install
npm run dev
npm test
npm run build
```
